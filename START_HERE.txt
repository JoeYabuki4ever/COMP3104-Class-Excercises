The app and Travis deployment files are prepared. Finish the online setup under
your GitHub and Travis accounts using the README.

1. Extract the ZIP.
2. Open Git Bash in the folder containing package.json.
3. Run these separately:

   npm install
   npm run build:pages
   npm start

4. Check the app at http://localhost:3000/ and stop the server with Ctrl+C.
5. Open README.md. Follow either "Continue in your existing Lab 05 repository"
   or "If you have not created an individual SPA repository".
6. Push the dep-inclusions branch to the individual SPA repository.
7. Connect that repository to Travis CI and save the hidden github_token variable.
8. Create a pull request from dep-inclusions into main, wait for the build to
   pass, review it, and merge. Wait for the new main build to deploy.
9. In GitHub Settings > Pages, choose Deploy from a branch > gh-pages > /(root).
10. Open the published website, capture your own required evidence, and submit
    according to D2L's Lab 06 instructions.

This local package is not an online deployment. No token is included. The
configuration automatically uses your actual SPA repository name during Travis
builds. The Group 10 text-file assignment is a separate repository task.
